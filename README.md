# Ocria Am7

Ocria Am7 is a Windows CLI automation tool for controlled browser-based
candidate review using local OCR. It preserves the confirmed BossOCR Legacy
baseline while establishing an independent Ocria product line.

- Product: Ocria
- Generation: Am7
- Executable: `Ocria.exe`
- Local package: `Ocria-Am7-Windows-x64.zip`

Ocria has a history-preserving provenance relationship with BossOCR. BossOCR remains
an independently maintained Legacy Stable product and a manual fallback; Ocria
does not provide automatic runtime fallback. See
[`docs/am7/PROVENANCE.md`](docs/am7/PROVENANCE.md) for the confirmed source and
remote boundary, and [`docs/README.md`](docs/README.md) for detailed Windows
usage and local build instructions.

AM7-R01 C03 changes active identity only. It does not create or publish a
release; the active workflow retains its known missing Release Notes input and
is not claimed to be presently publishable.
