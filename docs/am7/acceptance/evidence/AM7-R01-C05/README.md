# AM7-R01 C05 Automated Acceptance Evidence

This directory records the C05 Night Batch acceptance execution. Every record
is repository-relative and sanitized: it excludes credentials, real BOSS page
content, candidate data, screenshots, and local absolute paths.

The C05 execution starts from the uncommitted, governed C01--C04 workspace.
Its final status is determined only by the commands and contracts recorded in
this directory; it does not replace the required human MS-01--MS-12 smoke.
