# AM7-R01 C02 Evidence Index

All C02 evidence is repository-relative and contains commands, timestamps,
exit codes, remote URLs, immutable Git identifiers, and scope results only.
No credential, local absolute path, OCR body, screenshot, or runtime data is
retained.

| Evidence | Purpose |
| --- | --- |
| `command-manifest.md` | C02 command authorization and zero-push manifest |
| `before-configuration.log` | Pre-change remote, origin, URL-rewrite, ancestry, and workspace audit |
| `configuration-and-verification.log` | Local remote configuration and exact after-state verification |
| `final-verification.log` | Final metadata/provenance, diff, and allowed-file verification |
